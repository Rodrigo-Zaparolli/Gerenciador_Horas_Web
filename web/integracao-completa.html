Conectar o E-Desk neste computador

Este pacote completo permite enviar horas, comentários e fases pelo app web. Também abre pastas e planilhas originais neste PC.

Baixar integração completa para Windows

Atualização para % Realizado: se já usa a integração, execute Parar integração E-Desk.cmd na pasta atual. Extraia o novo ZIP nessa mesma pasta, substituindo os arquivos, e execute Iniciar integração E-Desk.cmd. Isso preserva os dados e o login do E-Desk nesse computador.

  1. Baixe o ZIP e use Extrair tudo para colocá-lo em uma pasta permanente.
  2. Na pasta extraída, dê dois cliques em Iniciar integração E-Desk.cmd.
  3. Clique abaixo para verificar a conexão. Se o navegador pedir acesso à rede local ou a este dispositivo, escolha Permitir.

Aguardando a verificação.

Abrir o app

Atualize o app com Ctrl + F5. Ao enviar as horas, entre no E-Desk se o navegador da integração solicitar login. O envio usa o script fornecido, sem a confirmação da extensão.

Depois de reiniciar o Windows, execute Iniciar integração E-Desk.cmd novamente. Não precisa instalar Python nem atualizar a extensão para usar este procedimento.

O espelho da planilha utiliza o Microsoft Excel instalado no PC. A verificação abaixo não cadastra horas.
