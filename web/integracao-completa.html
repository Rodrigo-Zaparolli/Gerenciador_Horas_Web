Conectar o E-Desk neste computador

v45: tipo do projeto pelo titulo da solicitacao. Identifica Enterprise ou Professional pelo produto informado no cabecalho. Mantem a leitura dos IDs reais, Tipo de Trabalho, Tempo Estimado e datas na tabela Trabalhos, alem das correcoes anteriores.

Este pacote completo permite enviar horas, comentários e fases pelo app web. Também abre pastas e planilhas originais neste PC.

Já tenho a integração: baixar correção leve

Para uma instalação completa já existente: aguarde os envios terminarem, execute Parar integração E-Desk.cmd, extraia a correção na mesma pasta substituindo os arquivos e execute Iniciar integração E-Desk.cmd. Preserve a pasta .edesk-local e os demais arquivos. A correção leve não funciona sozinha em uma pasta nova.

Baixar integração completa para Windows

Vínculos preservados nas atualizações: nesta primeira atualização, aguarde qualquer envio terminar e execute Parar integração E-Desk.cmd na pasta atual. Extraia o novo ZIP nessa mesma pasta, substituindo os arquivos e mantendo a pasta .edesk-local. Execute Iniciar integração E-Desk.cmd. Os vínculos existentes serão migrados automaticamente, preservando os originais.

A partir desta versão, os vínculos ficam no perfil do Windows, separados da pasta extraída. Atualizações futuras da integração não exigem selecionar novamente as pastas e planilhas já autorizadas nesse computador e usuário. Atualizar apenas o app web não exige reinstalar a integração.

  1. Baixe o ZIP e use Extrair tudo para colocá-lo em uma pasta permanente.
  2. Na pasta extraída, dê dois cliques em Iniciar integração E-Desk.cmd. Isso também ativa o início automático para seu usuário do Windows.
  3. Clique abaixo para verificar a conexão. Se o navegador pedir acesso à rede local ou a este dispositivo, escolha Permitir.

Aguardando a verificação.

Abrir o app

Atualize o app com Ctrl + F5. Ao enviar as horas, entre no E-Desk se o navegador da integração solicitar login. O envio usa o script fornecido, sem a confirmação da extensão.

Nas próximas entradas no Windows, a integração inicia em segundo plano, sem abrir o navegador. Mantenha a pasta extraída no mesmo local. Para desativar, execute Desativar inicio automatico.cmd; para reativar, execute Ativar inicio automatico.cmd. O comando Parar encerra apenas a execução atual.
