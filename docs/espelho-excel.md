# Espelho da planilha no comentário

Cada trabalho usa seu próprio arquivo vinculado no editor. No modal de comentário, selecione a aba/intervalo da tabela: a integração local pede ao Microsoft Excel a imagem original desse intervalo. Ela mantém mesclagens, fontes, cores, bordas, larguras, alturas, formatos numéricos e barras da formatação condicional. O app apresenta a imagem; não reconstrói uma tabela com um modelo único.

Requer Microsoft Excel instalado no mesmo PC e o pacote de abertura local atualizado. Execute **Parar abertura local.cmd**, extraia o pacote novo e execute **Iniciar abertura local.cmd**. Planilhas já vinculadas neste computador continuam usando os originais. Salve as alterações no Excel antes de atualizar a prévia.

O arquivo é aberto em uma instância separada, em modo somente leitura, com macros e atualização de vínculos externos desativadas. A instância fecha sem salvar alterações no arquivo original. Não há imagem aproximada como alternativa quando a integração falha: o app mostra o motivo para corrigir a configuração. Uma prévia nova não altera imagens já salvas no histórico.
